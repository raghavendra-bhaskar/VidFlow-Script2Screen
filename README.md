# VidFlow — Script to Screen

> **Convert any script into a narrated MP4 — fully offline, no API keys required.**
> Record your screen, trim and merge clips, add AI narration, sync audio to the exact second,
> transcribe video to text, and auto-generate narration scripts from silent recordings —
> all in one local web app served over HTTPS.

## Quick start (automated)

### Windows
```powershell
# Run from the project directory in PowerShell
.\install.bat
```

### Linux / macOS
```bash
chmod +x install.sh
./install.sh
```

Both scripts:
1. Install FFmpeg (winget / apt / brew)
2. Create a Python virtual environment
3. Install all Python dependencies (`requirements.txt`)
4. Copy `.env.example` → `.env`
5. Generate a self-signed TLS certificate (`cert.pem` + `key.pem`) for HTTPS

---

## Manual installation

### 1. Install FFmpeg

**Windows (winget — built into Windows 10/11):**
```powershell
winget install --id Gyan.FFmpeg -e --source winget
# Restart PowerShell after install so PATH is refreshed
```

**macOS:**
```bash
brew install ffmpeg
```

**Ubuntu / Debian:**
```bash
sudo apt update && sudo apt install -y ffmpeg
```

Verify:
```bash
ffmpeg -version
ffprobe -version
```

### 2. Create a Python virtual environment

**Windows:**
```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
```

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Python dependencies
```bash
pip install -r requirements.txt
```

### 4. Configure environment
```bash
# Windows
Copy-Item .env.example .env

# Linux / macOS
cp .env.example .env
```

Edit `.env` — all keys are optional for offline/animated explainer mode.

### 5. Generate the HTTPS certificate
```bash
python gen_cert.py
```
This creates `cert.pem` and `key.pem` in the project root (valid 10 years, localhost only).

## Running the app

**Always use the venv Python** (so FFmpeg and all dependencies resolve correctly):

**Windows:**
```powershell
.venv\Scripts\python.exe -m streamlit run app.py
```

**Linux / macOS:**
```bash
.venv/bin/python -m streamlit run app.py
```

Open **https://localhost:8501** in your browser.
> First visit: your browser will warn about the self-signed certificate. Click **Advanced → Proceed to localhost** — this is safe for local use.

> **Note:** The app resolves FFmpeg via the Windows registry even if the process PATH is stale,
> so FFmpeg installed via winget will always be found automatically.

## HTTPS setup

HTTPS is enabled by default after `install.bat` / `install.sh`. To set it up manually:

```bash
# 1. Generate cert (requires 'cryptography' — included in requirements.txt)
python gen_cert.py

# 2. cert.pem and key.pem are now in the project root.
#    .streamlit/config.toml already references them:
#      sslCertFile = "cert.pem"
#      sslKeyFile  = "key.pem"

# 3. Start the app — it will serve on https://localhost:8501
.venv\Scripts\python.exe -m streamlit run app.py
```

To **disable HTTPS** (revert to HTTP), comment out the two SSL lines in `.streamlit/config.toml`.

> **Why HTTPS?** The browser screen-capture API (`getDisplayMedia`) and microphone access work on `localhost` over HTTP, but HTTPS is required when accessing the app from another device on the LAN (e.g., a tablet or a second PC).

## Tab 1 — Generate from script

Converts a plain-text script into a fully rendered MP4 with narration, scenes, and subtitles.

1. Choose **Video style** in the sidebar:
   - **Animated explainer** — fully offline, no keys required
   - **AI-generated scenes** — requires `GOOGLE_API_KEY`
   - **Stock footage** — requires `PEXELS_API_KEY`
2. Select **Narration voice**:
   - **Offline mode**: dropdown lists all installed system voices (Microsoft David, Zira, Hazel, etc.)
   - **Cloud mode** (`GOOGLE_APPLICATION_CREDENTIALS` set): Indian English Neural2 / Standard voices + **Voice pitch** slider
3. Adjust **Voice speed** (0.75× – 1.25×).
4. Paste your script (up to 20 sentences).
5. Click **Generate video**.
6. Download the MP4 or narration MP3.

## Tab 2 — Upload video + narrate

Add narration at **exact timestamps** in any existing video.

### Controls

| Control | Description |
|---|---|
| **Upload your video** | MP4, WebM, MOV, MKV |
| **Add segment** | Create a narration block at a specific start time |
| **Start / End (s)** | When narration should begin and finish (leave End blank for natural duration) |
| **Narration text** | Text spoken at that segment; leave blank for silence |
| **No-overlap mode** | Segments are placed without overlap; rate auto-adjusted to fit the window |

### Audio sync tips

- Leave **End** blank → TTS runs at the sidebar speed; no rate adjustment.
- Set **End** → the app generates TTS at 1× speed, measures the natural duration, then re-generates at an adjusted rate so the narration fits exactly.
- Narration is mixed with original audio if the video has an audio track (configurable).

## Tab 3 — Video editor

Three sub-tabs for non-destructive video editing, all powered by FFmpeg.

### ✂️ Trim

1. Upload up to 5 clips.
2. Play each video to find the exact cut point.
3. Use the **drag-handle timeline** or the **Trim from / Trim to** number inputs.
4. Click **✂️ Trim & save clips** — trimmed files saved to `trimmed_videos/`.

### 🔗 Merge

1. Upload the clips to join (from the Trim tab or any MP4/WebM).
2. Use **↑ / ↓** to set playback order.
3. Click **🔗 Merge into one MP4** — merged file auto-saved to `merged_videos/`.
4. **⬇ Download** or **💾 Save to video+narrated/** buttons persist after merge.

### 🔊 A/V Sync

1. Upload a **video** and an **audio file**.
2. Choose **Replace video audio** or **Mix with existing audio**.
3. Set **Audio start offset** (seconds delay before audio begins).
4. Click **🔊 Sync audio to video** — output saved to `video+narrated/`.
5. Download and Save buttons persist across reruns (stored in session state).

## Tab 4 — Transcript

Transcribes any video or audio file to text using **faster-whisper** (runs fully offline, no API key).

1. Upload a video or audio file.
2. Select the **Whisper model** (tiny → large-v3; larger = more accurate, slower).
3. Click **Transcribe** — the transcript appears with timestamps.
4. Download as **plain text (.txt)** or **SRT subtitle file (.srt)**.

> Requires `faster-whisper` (`pip install faster-whisper`). The model is downloaded on first use (~70 MB for `tiny`, ~3 GB for `large-v3`).

## Tab 5 — Screen recorder

Records your screen directly in the browser using the Web MediaRecorder API.

1. Click **▶ Start recording** — browser asks which screen/window/tab to share.
2. Record your content; the elapsed timer is shown.
3. Click **■ Stop recording** to finish.
4. Preview the recording and click **⬇ Download recording (WebM)**.
5. Upload the downloaded file via **Save recording to project** — saved to `screen_recordings/` with a timestamp name.
6. All saved recordings are listed below with individual playback and download buttons.

> HTTPS is recommended when accessing from a second device on the LAN so `getDisplayMedia` works without browser restrictions.

## Tab 6 — Auto-narrate from video

Analyses evenly-spaced frames from any video and writes a professional narration script.

### AI backend options

| Backend | Requirement | Notes |
|---|---|---|
| **Gemini (Google Cloud)** | `GOOGLE_API_KEY` in `.env` | Fast, high quality; uses `gemini-2.0-flash` by default |
| **Ollama (local)** | Ollama running at `localhost:11434` | Fully offline; needs a vision model (see below) |

When both are available a radio button lets you choose. When only Ollama is available it is selected automatically.

### Setting up Ollama for vision

```bash
# Install Ollama — https://ollama.com
ollama pull llava          # recommended general-purpose vision model
# or
ollama pull moondream      # lightweight, fast
# or
ollama pull bakllava       # BakLLaVA — strong visual understanding
```

> **Text-only models (e.g. `llama3`, `gemma3`) will return HTTP 400.** The UI shows a warning immediately when a non-vision model is selected. Pull a vision model before using this tab.

### Usage

1. Upload any video (silent recordings work best).
2. Set **Frames to sample** (4–16; more = better understanding, larger payload).
3. Add an optional **Context hint** (e.g. "DevOps CI/CD tutorial for HCL engineers").
4. Click **🤖 Analyse & write narration script**.
5. Edit the generated script, then copy it to **📝 Generate from script**.

## Tab 7 — Audio editor

Three sub-tabs for audio-only editing.

### 🎤 Text → Audio (TTS)

- Type or paste any text.
- A live **word count + estimated duration** (MM:SS) is shown based on the current rate.
- Choose **MP3** or **WAV** output.
- Each generation is auto-saved with an **incremental filename** (`audio_001.mp3`, `audio_002.mp3`, …) so no file is ever overwritten.
- **💾 Save to audio/** copies to the `audio/` folder.

### ✂️ Trim audio

- Upload any audio file (MP3, WAV, M4A, AAC, OGG, FLAC).
- Set **Start** and **End** trim points.
- Output saved to `audio_edits/`.

### 🔗 Merge audio

- Upload multiple audio files; reorder with **↑ / ↓**.
- Click **Merge** → all files re-encoded to MP3 192 kbps and concatenated.
- Auto-saved to `audio_edits/`; **💾 Save to audio/** button also available.

## Full workflow: Record → Narrate → Export

```
1. Tab 5  → Record screen → Stop → Download WebM → Upload to "Save recording to project"
2. Tab 6  → Upload saved recording → Analyse → edit generated script
3. Tab 2  → Upload video → paste script → set segment timestamps → Generate narration & merge
4. Tab 3  → Trim sub-tab (optional) → clean up start/end
5. Tab 3  → A/V Sync sub-tab (optional) → replace audio with polished TTS from Tab 7
6.         → Save to video+narrated/ → final MP4 ready
```

## API keys (all optional)

All keys are optional. The app works **fully offline** in **Animated explainer** mode with local `pyttsx3` TTS and Ollama for auto-narration.

| Key | Purpose | Where to get it |
|---|---|---|
| `GOOGLE_APPLICATION_CREDENTIALS` | Google Cloud TTS (neural Indian English voices + pitch) | [Cloud Console](https://console.cloud.google.com/) → Text-to-Speech API → Service account JSON |
| `GOOGLE_API_KEY` | Gemini image generation (AI scenes) + Auto-narrate vision | [Google AI Studio](https://aistudio.google.com/) |
| `PEXELS_API_KEY` | Stock footage search | [Pexels API](https://www.pexels.com/api/) |

Set them in `.env` (copy from `.env.example`). **Never commit `.env` to source control.**

## Important limitations

- AI scenes are still images animated with zoom — not fully synthetic video.
- Talking AI presenter requires a separate vendor API and is not yet implemented.
- Subtitles use sentence-level timing approximations, not word-level alignment.
- Ollama auto-narrate requires a vision-capable model; text-only models return HTTP 400.
- Cloud TTS and Gemini may incur charges — check provider pricing and quotas.
- Pexels stock clips are subject to their API terms; review attribution requirements.
- The self-signed HTTPS certificate will trigger a browser security warning on first use —
  this is expected and safe for local development.
